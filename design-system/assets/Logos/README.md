# Logos

`eye-site-logo.png` is the full lockup: the navy eye arc (`navy`, #102040), the figure in the blue-figure → sky → mist gradient, EYE SITE in navy spaced caps and SACRAMENTO in blue-deep. It is a 522 × 568 PNG with a white background, so on light surfaces place it directly; on `navy` or a photograph, place it on a `canvas` tile with `radius-md` and `space-4` inner padding, as the current website does.

Clear space is `space-6` (24px) on all sides at web sizes and 48px on social graphics. Minimum width is 120px on the web and 180px on a post. Never recolor, stretch, crop the wordmark or redraw the mark. The eye arc alone may be cropped from this file as a large corner motif.
