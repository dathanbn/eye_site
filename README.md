# Eye Site Sacramento

Website and design system for Eye Site Sacramento Medical Group, an ophthalmology and optometry practice with offices in Sacramento and Folsom.

## What's here

- `site/` — the website. Plain HTML, CSS and JavaScript, no build step. Open `site/index.html` in a browser or serve the folder with any static server. GitHub Pages deploys this folder automatically on every push to `main`.
- `DESIGN.md` — the design system in a single file an AI agent can read (Google Stitch DESIGN.md format): colors, type, spacing, components, voice, do's and don'ts.
- `design-system/` — the same system as tokens, a brand book, a social media kit and component previews, mirrored from the Claude Design System artifact.
- `brand/` — logo files: the official transparent PNG, a cropped eye mark, and the original white-background PNG.

## Editing the site

Each page is a standalone HTML file in `site/`. Text lives directly in the markup. Colors and fonts are named at the top of `site/styles.css`. Images are in `site/assets/img/`; originals from the previous website are kept in `site/assets/img/harvest/` and stock photo credits are in `site/assets/img/stock/CREDITS.md`.

The appointment form validates and shows a confirmation but does not send anywhere yet. Point it at a form service or an email handler before launch.
